# Светлячок: Совиная ночь

Гиперказуальная 2D-головоломка жанра **Swipe / Draw Puzzle** для Godot 4.7 (Web / Яндекс Игры).

## Идея
Ночной лес. Нарисуй пальцем путь светлячка от места старта до банки-домика.
**Фишка (из Superhot):** время в лесу идёт, *только пока растёт линия*. Пока ведёшь линию,
совы поворачивают головы, засыпают и просыпаются, пауки качаются — ровно туда,
где они будут в момент, когда светлячок долетит до кончика линии. Ты «рисуешь будущее».

* Длина линии = время = запас света (полоска сверху).
* Совы видят всё в своём луче; жёлтый луч становится красным, если кончик линии в опасности.
* Кусты прячут светлячка. Чтобы «подождать», покрути линию внутри куста.
* Колючки — нельзя касаться. Пауки на паутинках — выбери момент.
* Ведёшь палец назад по линии → она стирается, время отматывается.
* Палец замер → время стоит: лес сереет, музыка «плывёт», частицы замирают.
* Звёзды: ★ дом, ★ вся роса, ★ экономно (уложился в норму света, отметка на полоске).
* Свет кончился → линия не растёт, но её можно стереть назад.
* Отпустил палец → светлячок летит по линии. Провал → быстрая перемотка назад.
* На уровнях 1–4 обучающая рука показывает путь, и лес «проигрывает» будущее вместе с ней.
* На остальных уровнях кнопка-лампочка 💡 в HUD показывает решение той же рукой.

## Главы (30 уровней)
| Глава | Уровни | Новое |
|---|---|---|
| 1. Ночной лес | 1–10 | совы, кусты, колючки, пауки, роса |
| 2. Болото | 11–20 | **лягушки** (язык по таймеру, горло раздувается перед выстрелом), **кувшинки** (укрытие, которое тонет по таймеру; круги на воде перед всплытием), **камыши** (обычное укрытие) |
| 3. Грибная поляна | 21–30 | **паутина** (внутри время идёт ×2: линия короче, мир успевает больше), **светогрибы** (пока горит, любая неспящая сова видит светлячка, даже в кусте) |

Все 30 уровней проверены решателем: каждый проходится на 3 звезды, норма `par_ink` = лучшее решение × 1.3.
В меню главы листаются стрелками, следующая глава открывается после последнего уровня предыдущей.

## Запуск
Открой `project.godot` в Godot 4.7 → F5. Первая загрузка импортирует ресурсы.
Экспорт: *Проект → Экспорт → Web (Яндекс Игры)* (preset уже настроен: без потоков,
`thread_support=false`, это важно для Яндекс Игр, т.к. там нет заголовков COOP/COEP).

## Структура
```
scenes/main.tscn            главная сцена (мир, линия, камера, HUD, окна, меню)
scenes/levels/level_XX.tscn 30 уровней — только инстансы сцен-объектов
scenes/objects/*.tscn       светлячок, сова, паук, куст, колючки, роса, банка, грибы,
                            лягушка, кувшинка, камыши, паутина, светогриб, рука-подсказка
scenes/ui/*.tscn            HUD, меню, кнопка уровня, окна победы/поражения
scenes/background*.tscn     фоны глав: лес / болото / грибная поляна
scenes/audio.tscn           все звуки (автозагрузка Sfx)
scripts/                    только логика и анимации, объекты в коде не создаются
ui/theme.tres               общая тема интерфейса, шрифты Noto Sans (кириллица)
```

## Как сделать новый уровень (в редакторе, без кода)
1. Дублируй `scenes/levels/level_10.tscn`.
2. Перетаскивай инстансы из `scenes/objects/`. Маркер `Start` — старт светлячка, `Jar` — цель.
3. Параметры совы (угол, размах поворота, дальность, сон/бодрствование) правятся в инспекторе,
   луч взгляда виден прямо в редакторе (скрипт `@tool`).
4. У корня уровня задай `max_ink` (запас света), `par_ink` (норма для третьей звезды), `hint` (подсказка)
   и `chapter` (0 — лес, 1 — болото, 2 — поляна; определяет фон).
5. Лягушка: `angle`, `reach`, `period`, `active`, `offset`. Кувшинка: `radius`, `period`, `up` (сколько секунд
   на поверхности), `offset`. Паутина: `radius`, `rate`. Светогриб: `radius`, `period`, `lit`, `offset`.
   Все объекты `@tool`: направление языка, размеры и зоны видны прямо в редакторе.
6. Маршрут руки: инстанс `scenes/objects/tutorial.tscn` (Path2D), кривую рисуешь в редакторе.
   `auto_play = true` — обучение (показывается само), `false` — подсказка по кнопке-лампочке.
7. Добавь сцену в массив `levels` узла `Main` и поменяй `LEVEL_COUNT` в `scripts/progress.gd`.

## Точки интеграции Яндекс SDK
* **Сохранения:** `scripts/progress.gd` → `load_data()` / `save_data()` (сейчас `user://save.cfg`).
* **Звук / фокус:** `scripts/sfx.gd` → `_notification()` глушит звук при потере фокуса;
  туда же можно добавить паузу на время рекламы (`get_tree().paused = true`).
* **Межуровневая реклама:** `scripts/main.gd` → `load_level()` (вызывается по кнопке «Далее»/«Заново»).
* **Rewarded-реклама** (например, +свет): `_out_of_ink()` в `scripts/main.gd` вызывается, когда свет закончился;
  достаточно увеличить `level.max_ink` после просмотра.
* **Rewarded-реклама за подсказку:** `_on_hint_pressed()` в `scripts/main.gd`: покажи рекламу
  и вызови `_grant_hint()` в колбэке награды. Подсказка остаётся открытой до смены уровня.
* **GameReady / LoadingAPI.ready():** конец `_ready()` в `scripts/main.gd`.
* **Gameplay start/stop:** `_begin_draw()` / `_win()` / `_fail()` в `scripts/main.gd`.
